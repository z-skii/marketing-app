# Design references

`tapmart-primary-reference.png` is TapMart's primary visual north star: the
quality bar for how the product should look and feel. It is not a template
and not a screen to copy. The design reviewer (`npm run design-review`)
sends it with every review next to the current screen and the product
brain, and compares confidence, hierarchy, spacing, media prominence,
surfaces, lime restraint, chrome, depth, density and motion.

Replace the file to change the north star; keep the name so the reviewer
finds it. Extra references can be passed with `--reference <file>`.
