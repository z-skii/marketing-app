# V2 art direction: User Home

By Astra, TapMart's design director.

**Two seconds.** A large reference can earn US$75, a finished Story can earn US$25 after its live time and approval, and a car campaign offers US$300 per month. Each object has one View action. This is opportunity discovery, not an earnings dashboard or a work inbox.

**Signature.** The earning edge: an oversized reference still, a narrow intact Story and a grounded landscape car photograph terminate at the same straight line on desktop. Three different ways to earn become three precisely aligned money-and-action bands. This unequal silhouette with a shared earning boundary—not a decorative card treatment—is the distinctive TapMart moment.
