## States

- 1. Enter populated visits Home: render the committed local projection immediately, with Business selected and the preserved Home scroll position.
- 2. Inspect a count: open its definition and one contextual drill-down action. Closing returns focus to the same count without changing data.
- 3. Inspect Live: show qualified program status. Last Wallet update expands within that panel; View program navigates to the actual program route.
- 4. Leave for a working task: View QR, Add visit, member, attribution, program or Send update opens its specified V3 route. These destination workflows are not inline Home states.
- 5. Return after a committed event: read the provider’s new counts, recent order, reward states and source projection. Do not replay scanner, redemption or Wallet-success choreography on Home.
- 6. Return after a business Wallet update: counts and recent ordering remain unchanged. Last Wallet update reflects the stored simulation; Send update is unavailable until the next business day.
- 7. Return after a reward edit: show the new active rule in the program presentation. Each member’s row continues to use its own retained cycle version.
- 8. No program: retain the shell, title and Lab context; replace all operational sections with the loop mark and Turn visits into rewards. Header action becomes Create program.
- 9. Draft: retain the shell; show actual draft artwork, Free coffee, 5 visits, Draft and Last completed: Reward. Continue setup opens Card. Preview card opens the same creation step focused on its preview without saving or launching.
- 10. Live-zero: header action becomes View QR; show four zeros and the honest empty recent area. Show the real live program, an empty source explanation and working links. Send update is disabled with its audience reason.
- 11. Points contexts: replace the visits cohort with the specified single-member points fixture. Header and recent unit change; no five-stroke stamp graphic or arbitrary balance editor appears.
- 12. Counter QA contexts: Same-day visit, Wallet not added, Google limit reached and Recording error retain valid Home projections until a deliberate downstream action changes them. Selecting a scenario itself does not count a visit.
- 13. Lab selection: selecting a new scenario or Reset demo opens Change demo state? Only Change state replaces the provider. Cancel retains both local data and current scroll.
- 14. Asset failure: retain the reserved artwork and all real textual program content. Local state-read failure instead replaces the body with the explicit retry state; do not guess counts.
- 15. Shared navigation boundary: unimplemented shell destinations open the supplied outside-preview notice. Browser Back dismisses the top layer before leaving Home.
