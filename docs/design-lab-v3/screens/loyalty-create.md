# V3 art direction: Create program

By Astra, TapMart's design director.

**Two seconds.** Choose the rule. See the actual card. Put its signup QR on the counter, entirely simulated here.

**Signature.** The return becomes an object before it becomes administration: five quiet strokes establish the rule, the same rule inhabits a recognizable Wallet card, and that card hands off to one counter QR. TapMart-specific continuity replaces a generic form wizard. Nothing deliberately defective is added to satisfy the schema's wording.
