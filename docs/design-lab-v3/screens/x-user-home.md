## truth

- All visible records are fictional fixtures in an isolated coded preview. Nothing on this surface changes production sessions, applications, requests, submissions, earnings or payouts.
- US$75 and US$25 are opportunity amounts, not balances. Keep On approval adjacent. US$300 retains /month and Monthly approval.
- When an authoritative amount is gross-only, add Before fee at discovery. Never infer a fee or calculate a take-home amount from an assumed percentage.
- Remaining spots, closing date, Story duration, business identity, follower threshold, city and campaign duration resolve from their own records. Missing values are not replaced with plausible examples.
- The short closing date must represent the actual deadline. Detail exposes the complete date, time and timezone. Do not reuse a date merely because it is legible in the supplied capture.
- Story posting requires a valid creative and a supported handoff. Opening a preview or external destination is not proof of posting.
- A car photograph is not a model, and campaign imagery is not automatically the user's listed vehicle. A placement plan requires this opportunity's supported zone mapping.
- Opening a direct-request fixture preserves its real Accept / Decline boundary. Ordinary discovery is not restyled as an accepted assignment.
- Unsupported financial, rights or eligibility information blocks commitment rather than being concealed. Detailed states are not subject to the feed's word ceiling.
- No attention strip appears by default. Only an existing, qualifying urgent action or blocking financial issue may introduce one, with its actual copy and a separately measured state.

## two second read

A large reference. US$75 on approval. View. A tall Story and a wide car offer two visibly different ways to earn below.

## thesis

User Home is a short, inspectable collection of paid-work opportunities, not a stack of cards. One generous reference establishes the media-to-money relationship; a freestanding Story changes the silhouette; a broad car photograph changes it again. Facts stay on opaque reading surfaces, while the phone navigation alone supplies a thin layer of optical depth. Opening an opportunity preserves the same media and reveals its real requirements and financial boundary; returning restores the exact place the person was browsing.

## engineering notes

- Build only under /design-lab-v3 and its supporting V3 files. Inspect the repository for actual route/query conventions, fixture relationships, available actions and manifests before implementation. Leave V2 and production untouched.
- Use bundled DM Sans throughout. Ink #17221E; muted text #59655D at full opacity. Titles 18px/24px, weight 600; actions 14px/20px, weight 600; supporting facts and basis 13px/18px; navigation 12px/16px minimum; obligations 16px/24px. Money is 36px on phone, 44px desktop, weight 600 with tabular lining numerals.
- Default stacking: canvas z0, media z10, opaque reading surfaces z20, solid desktop sidebar z30, phone navigation lens z40, its controls z50. Modal scrim z60; opaque task z70; task-local media z80, reading layer z90 and compact control header z100. Do not leave the underlying navigation active or visible through a modal task.
- Canvas material: #F6F7F5, blur 0, saturation 1, no border, highlight or shadow, radius 0. Reading material: #FFFFFF, blur 0, saturation 1, no enclosing border, optional exposed 1px #DCE2DE separator, inset highlight 0 1px 0 rgba(255,255,255,0.9). No shadow when in document flow.
- Navigation lens: rgba(255,255,255,0.58), backdrop blur 16px, saturation 1.16, radius 18px, 1px masked 135-degree edge from rgba(255,255,255,0.88) through rgba(255,255,255,0.16) to rgba(223,234,225,0.64), inset highlight 0 1px 0 rgba(255,255,255,0.74), shadow 0 8px 28px rgba(46,74,60,0.09). Increase local opaque backing if contrast fails.
- No optical image-duplicate refraction on this feed. That treatment is reserved for the controlled public moments. Default User Home has one active backdrop-filter region; a modal may replace it with one compact task-header lens. Never nest filters; keep visible blur area below 20% of the viewport.
- Primary View controls use #17221E with white text, radius 12px, blur 0, no shadow in flow. Minimum 44×44px targets. Focus is a 2px #315E49 outline with 3px offset; use white on dark media.
- Use opaque #FFFFFF navigation/header substitutes for reduced transparency, unavailable backdrop filtering or failed contrast. There is no full-screen backdrop blur.
- Reserve intrinsic image dimensions and stage space before loading. Produce source-preserving responsive derivatives, approximately 720px wide for the phone reference, 480px for the phone Story and 800px for the car; desktop candidates up to 960px for the reference and 512px for Story. Never upscale beyond useful source resolution. Review actual crops and bytes.
- Prioritize only the leading reference. Budget approximately 200KB for it and 120KB for Story where quality permits; lazily load the car and expanded originals. Count all media actually fetched during initial loading against the 350KB target, including near-viewport lazy loads.
- Implement opening continuity through measured start/end rectangles, clipped wrappers and transform/opacity animation. Measure once per transition; never alternate layout reads and writes each frame. Preserve the image's aspect ratio rather than stretching pixels between different bounds. Do not animate layout dimensions, shadows or blur.
- At most one active video decoder if a genuine reference video exists. Pause off-screen media, honor data saving and reduced motion, and use its real poster. The still-based fixture has no playback UI.
- Use existing isolated preview state. Save, filters and local identity changes must not reach production. Preserve any existing request drafts and use the existing discard confirmation when meaningful input would be lost.
- At 320px, use 12px page padding, 32px money and a leading reference stage capped at min(360px, 100svh minus 288px), contained without stretching. Allow the reading band to grow naturally. At 200% text zoom, switch Story to creative followed by its reading surface, expand all text regions and make navigation wrapping-safe. No clipping to preserve a capture.
- Record actual page heights and text totals in TEXT_COUNTS.md, results in PERFORMANCE.md, source/crop/state mappings in MEDIA_MANIFEST.json and actual implemented files in FILE_MAP.md. Proposed output names are not evidence that files already exist.
