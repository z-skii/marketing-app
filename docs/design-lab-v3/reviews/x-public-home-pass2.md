## Spec was wrong

- The desktop specification allowed too much separation between media, reading edges and stage-wide controls. In the real page, that freedom produces empty spans and orphaned actions; controls need stronger local ownership.
- Removing blanket minimum heights was correct, but natural height alone is not a complete sequence-layout strategy. It needs stable local anchors and deliberate handling of shorter endpoint states.
- Repeating the same player vocabulary across nearly every act makes the implementation read like a demo index. Keep consistent operation, but make the controls subordinate to each object's actual footprint.
- The optical-rim recipe does not guarantee convincing material. The visible thick plaque should be simplified rather than defended because it follows a material recipe.
